Core Capabilities

Why Choose Hybrid RAG?

Built for precision, transparency, and real-world performance.

Hybrid Retrieval Engine

Combines BM25 keyword precision with FAISS dense semantic search. Alpha parameter lets you tune the balance for your use case.

Live Web Augmentation

Automatically integrates web search results when local documents don't have enough information, ensuring up-to-date answers.

Source-Verified Answers

Every response includes direct citations [DOC: filename.pdf] and [WEB: URL], so you can verify the source of each claim.

Advanced Configuration

Fine-tune chunk size, overlap, embedding models, LLM temperature, and system prompts for your specific domain.

Session & History

Persistent query history with export capabilities. Track your conversations and revisit previous answers.

RAGAS Evaluation Ready

Built-in evaluation harness using RAGAS to measure retrieval accuracy, context relevancy, and answer faithfulness.

Workflow

How It Works

Three simple steps from upload to answer.

01

Ingest & Parse

Upload your documents (PDF, DOCX, TXT, HTML, CSV). The engine extracts clean text with OCR for scanned PDFs.

02

Hybrid Indexing

Documents are chunked and dual-indexed via BM25 (keyword) and FAISS (semantic) for fast, accurate retrieval.

03

Query & Synthesize

The system retrieves the best snippets from both local store and web, then synthesizes a concise, cited answer via Gemini.
